# 구도 카메라

구도 가이드를 화면에 띄워 보면서 필터를 입혀 찍는 카메라 앱입니다.
설치 없이 휴대폰 브라우저에서 바로 쓸 수 있고, 홈 화면에 추가하면 앱처럼 동작하는 **PWA**로 만들었습니다.

## 기능

| 구분 | 내용 |
|---|---|
| 구도 가이드 | 3분할, 황금분할, 황금나선, 대각선, 삼각, 중앙, 수평선, 얼굴, 반신, 전신, 2인 |
| | 황금나선, 삼각, 수평선은 한 번 더 누르면 방향이 바뀜 · 노란 점은 피사체를 두면 좋은 위치 |
| 필터 (실시간) | 원본, 맑음, 따뜻, 피치, 크림, 필름, 시네마, 쿨, 빈티지, 흑백, 느와르 · 강도 조절 슬라이더 |
| | 필터 썸네일에 지금 카메라 화면이 그대로 보임 |
| 촬영 | 화면 비율(3:4 / 1:1 / 9:16), 타이머(3초/10초), 플래시(후면: 라이트, 전면: 화면 조명), 핀치 줌, 수평계 |
| 갤러리 | 앱 안에 저장(IndexedDB) · 공유 / 기기에 저장 / 삭제 |

필터는 WebGL 셰이더로 처리하므로 실제 저장되는 사진에도 미리보기와 똑같이 적용됩니다.

## 실행

카메라는 **HTTPS** 또는 `localhost`에서만 켜집니다.

```bash
npm start
```

PC에서 http://localhost:8080 으로 열어 확인할 수 있습니다.
휴대폰으로 테스트하려면 GitHub Pages, Netlify, Vercel 같은 곳에 이 폴더를 그대로 올려 HTTPS 주소로 접속하세요. (빌드 과정이 없습니다.)

## 파일 구성

```
index.html            화면 구조
style.css             디자인
js/app.js             카메라, 촬영, UI, 갤러리
js/filters.js         필터 프리셋 + WebGL 렌더러  ← 필터 추가/수정은 FILTERS 배열
js/guides.js          구도 가이드 그리기          ← 가이드 추가는 GUIDES 배열 + drawGuide의 case
js/store.js           사진 저장(IndexedDB)
sw.js                 오프라인 캐시
manifest.webmanifest  홈 화면 설치 정보
```

### 필터 만들기
`js/filters.js`의 `FILTERS`에 한 줄을 추가하면 됩니다.

```js
{ id: 'sunset', name: '노을', warmth: 0.8, saturation: 1.15, highlight: [0.08, 0.02, -0.04], vignette: 0.3 },
```

사용 가능한 값: `brightness`(밝기), `contrast`(대비), `saturation`(채도), `warmth`(색온도), `tint`(초록↔자주),
`fade`(물빠짐), `vignette`(비네팅), `grain`(필름 입자), `mono`(흑백), `shadow`/`highlight`(어두운/밝은 부분 색감 RGB)

## 플레이 스토어 출시

이 앱은 웹 기술로 만들어져 있어서 아래 방법 중 하나로 안드로이드 앱(.aab)으로 감쌀 수 있습니다.

1. **TWA (Bubblewrap)** – HTTPS로 배포한 주소를 그대로 앱으로 만듦. 가장 간단.
2. **Capacitor** – 앱 안에 파일을 넣어 오프라인 동작, 기기 갤러리에 바로 저장하는 등 네이티브 기능 추가가 쉬움.

## 알려진 제한

- 브라우저에서는 사진을 휴대폰 갤러리에 직접 넣을 수 없어 "저장"은 다운로드 폴더로, "공유"는 공유 메뉴로 갑니다. (Capacitor로 감싸면 해결)
- 줌은 디지털 줌입니다.
- 플래시(라이트)는 기기·브라우저가 지원할 때만 켜집니다. 지원하지 않으면 화면 조명으로 대신합니다.
